## 动词

用：安装 / 卸载 / 升级 / 更新 / 启动 / 重启 / 运行 / 停止 / 打开 / 查看 / 复制 / 重试 / 保存 / 删除 / 添加 / 移除 / 启用 / 停用 / 批准 / 允许 / 取消。

版本动作分两种。

- **更新**：把已装的东西换到来源上的最新版。按钮、进行中、结果、状态都用它：更新 / 全部更新 / 更新依赖 / 有新版本 / 更新中 / 更新失败 / 更新还没有生效。
- **升级**：必须换到更高一代才能继续（dsh、工作台、适配组件的最低版本要求）。只出现在说明句里，不作按钮、不作状态。

不写：装上 / 装好 / 卸掉 / 换上 / 换掉 / 点进去 / 点一下 / 跑一遍 / 跑一次 / 弄 / 搞 / 造 / 收工 / 上板 / 点头 / 粘到 / 自己动手。

## 状态

写：未安装 / 已安装 / 有新版本 / 更新中 / 更新失败 / 运行中 / 已完成 / 进行中 / 待处理 / 待查看 / 等待批准 / 已暂停 / 不可用 / 未就绪。

任务清单那一条用「已完成 / 进行中 / 待处理」三档，与 dsh 自己的任务清单同一套说法，不另造词。

不写：在跑 / 跑完 / 跑完没看 / 没在跑 / 起不来 / 没起来 / 活了 / 挂了 / 崩了 / 卡住。

## 双向禁词

### 内部词（不出现界面句与 agent 交代）

profile / adapter / schema / payload / bundle / patch / stderr / probe / unit / daemon / opencli / 外壳 / 投影 / 事实 / 宿主 / 套件 / 索引源 / 适配器集合 / 体检 / 模块 id / 产物目录 / 上下文 / 装配 / 收窄 / 落盘 / 兜底。

写法：换成界面词；换不了就移到技术细节（detail / 折叠区 / 日志）。日志与 CLI 可以用技术词，但要与界面词同源，且可 grep。

### 口语词（不出现界面句与 agent 交代）

这一下 / 这一块 / 这一跳 / 点进去 / 点头 / 上板 / 收工 / 在跑 / 跑完 / 起不来 / 盘上 / 装上 / 装好 / 卸掉 / 换上 / 弄 / 搞 / 造 / 就好 / 就行 / 帮你 / 替你 / 不用你点 / 粘到 / 自己动手 / 咱们 / 我们。

写法：查上面的动词与状态表；没有就补表。

### 工具链术语（文档首次出现给中文说法；命令名、规则号、代码标识照旧）

| 术语 | 中文说法 | 说明 |
|---|---|---|
| 门禁 | 自动检查 | 命令 `check`、规则号、`check:gates` 保留；句子首次出现写「自动检查（门禁）」 |
| 判据 | 检查项 | 规则名与「十四条判据」这类固定说法保留；句子写「检查项（判据）」 |
| 执行缝 | 命令执行入口 | `deps.seam` 保留 |
| 门面 | 统一入口 | 首次出现写「统一入口（门面）」 |
| 契约 | 接口约定 | 代码标识 `contract` 保留 |
| 棘轮 | 只减不增 | 例：例外清单只减不增 |
| 豁免表 | 例外清单 | |
| 归因 | 定位来源 | |
| 生字段 | 未知字段 | |

### 例外

- 日志、CLI、堆栈、detail：技术词可用，但同一概念必须与界面词同源。
- 高级设置页：术语可用，首次出现必须给界面词或一句解释。
- 命令、包名、参数名：原样，不翻译。

## 登记流程

1. 新概念出现：先加「内部词 → 界面词」一行，再写文案。
2. 界面词必须能在界面上找到；找不到，说明这个概念还没落地。
3. 同一概念只留一个词；旧词进禁词表。
