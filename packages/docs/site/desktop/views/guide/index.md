# 指南

按你要办的事选择一条。五条路径互不依赖。

## 安装并启动

<PagodaDocLinkToView view="guide/quickstart">快速开始</PagodaDocLinkToView>：在 Desktop 中安装、重新打开窗口、安装第一个模块。需要 Desktop 与一个能安装扩展的浏览器。

## 安装

<PagodaDocLinkToView view="guide/install">安装</PagodaDocLinkToView>：在 Desktop 的插件页安装一次；第一次打开会自动准备环境，浏览器里还要安装一次 OpenCLI 扩展。

## 让面板有东西

<PagodaDocLinkToView view="guide/modules">面板与模块</PagodaDocLinkToView>：面板能力来自模块，安装什么就有什么；没有现成的就让 agent 开启 DIY 现场创建。面板读取的是浏览器里的登录状态。请先安装 OpenCLI 扩展并保持浏览器打开，再按模块提示登录。

## 数据放在哪

<PagodaDocLinkToView view="guide/data">数据与设置</PagodaDocLinkToView>：会话、项目、附件放在 `~/.dsh` 下，安装或卸载工作台都不会修改；模型、主题、插件沿用 Desktop 的配置，工作台自己的开关只影响这份工作台；备份与清理都在这一页。
