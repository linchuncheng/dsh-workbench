# 数据与设置

一句话：**会话、项目、附件放在 `~/.dsh` 下，安装或卸载工作台都不会修改它们；设置页仍是同一个 Settings，工作台在里面多加了一组「工作台设置」，只影响这份工作台。**

| 内容 | 位置 |
| --- | --- |
| 会话 / 项目 / 附件 | `~/.dsh/{sessions,storages,attachments}` |
| dsh 的设置与插件（模型、主题、插件） | `~/.dsh/profiles/<名字>`；Desktop 下就是 Desktop 那份 |
| 工作台自己的开关（MCP 按需加载、尝鲜版本、模块模型、DIY 模式继承） | `~/.dsh/workbench/settings.json` |
| 工作台运行时（opencli、工坊、模块市场、自更新日志） | `~/.dsh/workbench` |

## 设置在哪

在 Settings 里。工作台在里面加了一组 **工作台设置**：会话列表、模块用的模型、MCP 按需加载、DIY 模式继承自、尝鲜版本。配置同步与新建工作台收在「高级」里。

会话列表切换后会自动刷新页面；工作台 DIY 改完在新会话生效。模型、主题、插件仍在 Settings 原来的分组里改，属于 dsh 自己的设置。

## 备份与清理

- 会话、项目、附件：位于 `~/.dsh/{sessions,storages,attachments}`，需要备份时复制这三个目录。
- 工作台运行时：`~/.dsh/workbench`，包含 opencli 的隔离运行时、工坊、模块市场与自更新日志。
- 恢复原样：在插件页移除工作台，再删除 `~/.dsh/workbench`。删除这个目录不会影响项目文件，也不会删除会话与项目。
- 浏览器里的 OpenCLI 扩展和平台登录状态不在这几个目录里。卸载工作台不会移除它们；不再使用时，请到浏览器的扩展页移除。

## 更换机器

在新机器上安装一次、登录一次；会话和项目位于 `~/.dsh` 下，需要时一并复制过去。
模块通过安装获得，重新安装一次比复制目录更可靠。
